# Tule Resort

Luxury resort guest experience and menu ordering system for **Tule Resort, Hawassa, Ethiopia**.

## Highlights

- Tule Resort branded guest experience
- Visual restaurant and cafeteria menus
- Menu categories with food imagery, prices and descriptions
- Guest ordering flow with persistent cart
- Supabase-powered menu, orders, rooms and resort services
- Admin and staff workflows
- Responsive Next.js interface

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open `http://localhost:3001` in your browser.

## Branding

The primary brand is **Tule Resort — Hawassa** with the tagline **“Relax. Enjoy. Remember.”**

The brand mark is stored at `public/tule-resort-mark.svg`.
